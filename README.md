# Java-Streams-API
This repo is all about how java streams work. I am going to explore features like Filter and Maps. 

Java streams: it is an abstraction, focusing on the all instead of the parts.
They work well with collections. e.g. Lists, Maps.

Imperative Approach:
Specifies every single detail like a if statements, looping and printing too long.

Declarative Approach:
No ifs and makes it easy to read as well.
